# Honsen WMS — 界面规范（UI Spec）

> 适用范围：**React 桌面版**（Next.js + Tailwind，pywebview exe 交付）  
> 设计风格：品牌蓝 + 深色侧边栏 + 浅色商务内容区  
> 参考：原 PyQt6 主题 `theme/theme.qss`

---

## 1. 设计原则

1. **业务优先**：表格与筛选是核心。
2. **语义一致**：颜色表达操作含义。
3. **规范录入**：遵守 PD 数据录入准则。
4. **桌面窗口**：按 1280×800 设计，最小宽度 1024px。

## 3. 布局结构

### 3.1 App Shell（登录后全局）

```
┌──────────┬──────────────────────────────────────────────┐
│ Sidebar  │  [筛选工具栏]                                  │
│ 200px    ├────────────────────────┬───────────────────┤
│          │  数据表格（可勾选）     │  编辑/出入库面板     │
│          │  sticky 表头 · 可滚动   │  376px             │
│          ├────────────────────────┴───────────────────┤
│          │  底部状态栏                                    │
└──────────┴──────────────────────────────────────────────┘
```

- 实现：`PageLayout` + `AppShell`；库存页、交易页使用主从分栏；设置页全宽滚动。
- **侧边栏宽度**：`200px`；内容区 `h-screen` 无外边距。
- **右侧面板**：空态虚线提示；表单态白底卡片。
- **最小窗口宽度**：`1024px`（pywebview `min_size`）。

### 3.2 登录页（独立布局）

```
┌─────────────────────────────┐
│ 品牌蓝顶栏 56px              │  ← logo + 系统名
├─────────────────────────────┤
│     page-bg                 │
│   ┌───────────────────┐     │
│   │ 登录卡片 居中       │     │  ← 宽 380–400px
│   │ · 标题 + 副标题     │     │
│   │ · 账号 / 密码       │     │
│   │ · 测试连接 | 初始化   │     │
│   │ · [登录系统] 主按钮   │     │
│   │ · 数据库路径（弱化）  │     │
│   └───────────────────┘     │
└─────────────────────────────┘
```

- 窗口/视口固定感：`max-width: 440px` 居中卡片容器。
- **不展示**大块只读数据库配置表单。

## 5. 组件规范

### 5.1 Button

| 变体 | 背景 | 文字 | 用途 |
|------|------|------|------|
| `primary` | brand-primary | 白 | 筛选/刷新、登录 |
| `success` | success | 白 | 新增、入库 |
| `danger` | danger | 白 | 删除、出库 |
| `info` | info | 白 | 编辑、导出 |
| `warning` | warning | 白 | 冲销、导入、初始化 DB |
| `accent` | accent | 白 | 批量编辑 |
| `muted` | muted | 白 | 删除记录（交易） |
| `outline` | 透明 + 边框 | text-primary | 测试连接 |

- 高度：默认 `36px`；登录主按钮 `44px`。
- 禁用：`opacity: 0.5`，`cursor: not-allowed`。

### 5.2 Input / Select

- 高度：`36px`，内边距 `8px 12px`。
- 边框：`1px solid #cbd5e1`；聚焦 `2px solid #3f51b5`。
- 只读：背景 `#f1f5f9`，文字 `#64748b`。
- **下拉列表**：最少显示 **6 行**空间（`min-height: 192px`），不足 6 项也保留高度；最多可见 12 项后滚动。

### 5.3 DataTable

| 属性 | 规范 |
|------|------|
| 表头背景 | `#f1f5f9` |
| 表头底边 | `2px solid #3f51b5` |
| 斑马纹 | 偶数行 `#f8fafc` |
| 选中行 | 背景 `#c5cae9`，文字 `#1a237e` |
| 行高 | `40px` |
| 操作 | 行点击选中；支持多选（库存批量操作） |
| 空状态 | 居中图标 +「暂无数据」+ 引导操作 |

### 5.4 Card

- 背景白、圆角 10px、边框 `#e2e8f0`、内边距 16px。
- 用于包裹每个页面的主内容区。

### 5.5 Dialog / Modal

- 遮罩：`rgba(0,0,0,0.4)`。
- 宽度：表单类 `480px`；批量编辑 `640px`；宽表格选择 `800px`。
- 结构：标题 → 内容 → 底部按钮栏（右对齐：取消 + 确认）。
- 危险操作（删除、冲销、导入覆盖）：确认按钮用 `danger`，附二次确认文案。

### 5.6 Toast / 消息

| 类型 | 左边条色 | 场景 |
|------|----------|------|
| success | success | 保存成功、导入完成 |
| error | danger | 库存不足、登录失败 |
| warning | warning | 导入风险提示 |
| info | info | 连接测试成功 |

- 位置：右上角；自动消失 4s；错误可手动关闭。

### 5.7 底部状态栏（页面内）

- 背景 `#f8fafc`，上边框 `#e2e8f0`。
- 内容示例：`总计 128 条记录 · 已选 3 条`。
- 交易页额外展示：入库合计 / 出库合计。

## 6. 页面级规范

### 6.1 库存管理 `/inventory`

**工具栏左→右：**

1. 搜索框（placeholder：`搜索：名称、型号或柜号`）
2. 类别 / 专业 / 储存位置 三个 Select
3. `刷新`（warning）
4. （弹性空间）
5. `新增物品`（success）· `编辑物品`（info）· `批量编辑`（accent）· `删除物品`（danger）

**表格列：**

`ID` · `名称` · `物品型号` · `材料类别` · `专业类别` · `单位` · `当前库存` · `最小库存` · `储存位置` · `柜号` · `库存状态`

- `ID` 列可隐藏或置末列（设置项，默认显示）。
- 数字列右对齐。

### 6.2 交易记录 `/transactions`

**操作栏：** `入库 IN`（success）· `出库 OUT`（danger）· `修改记录`（info）｜ `冲销`（warning）· `删除`（muted）

**筛选区（两行）：**

- 行1：从日期 · 到日期
- 行2：类别 · 专业 · 地点 · 项目 · 类型 · 物品搜索 · `筛选/刷新`（primary）· `导出 CSV`（info）

**表格列：**

`ID` · `日期/时间` · `物品名称` · `物品型号` · `数量` · `储存位置` · `柜号` · `专业` · `类型` · `来源柜号/接收人` · `项目`

- 「柜号」：入库为 `recipient_source`（来源柜号），出库为 `Inventory.cabinet`。
- 类型 `IN` 绿色标签，`OUT` 红色，`REVERSAL-*` 橙色。

**入库表单：**

| 字段 | 说明 |
|------|------|
| 选择物品 | 库存条目 |
| 数量 | 必填 |
| 来源柜号 | 必填，写入 `recipient_source` |

### 6.3 系统设置 `/settings`

**基础配置：** 2 列网格卡片，每卡片含：标题 → 输入+添加 → 列表 → 删除选中。

**数据导入/导出：** 两个 section 卡片；导入前显示红色警告文案。

## 7. 交互规范

| 场景 | 行为 |
|------|------|
| 删除物品 | 弹窗确认，提示将同时删除所有关联交易 |
| 出库库存不足 | 阻止提交，Toast 错误 |
| 冲销 | 确认后生成反向记录，原记录保留 |
| 导入 CSV | 二次确认 + 完成后展示 inserted/updated/failed 统计 |
| 登录失败 | 表单内联错误 + Toast |
| 401 未授权 | 清除 token，跳转 `/login` |
| 加载中 | 表格区域 Skeleton 或 Spinner，按钮 disabled |

## 8. 响应式断点

| 断点 | 行为 |
|------|------|
| `≥1280px` | 标准桌面布局 |
| `1024–1279px` | 侧边栏可折叠；筛选器可换行 |
| `<1024px` | 暂不支持（显示提示「请使用桌面浏览器」） |

---

## 9. 无障碍（基础）

- 表单控件必须有 `<label>` 或 `aria-label`。
- 按钮文字不得仅靠颜色区分（需图标或文字并用）。
- 对比度：正文与背景 ≥ 4.5:1。

## 10. Tailwind 映射建议

```js
// tailwind.config.ts theme.extend.colors
brand: {
  primary: '#3f51b5',
  'primary-hover': '#5c6bc0',
  'primary-dark': '#283593',
},
sidebar: {
  bg: '#1a237e',
  text: '#c5cae9',
  active: '#3f51b5',
  accent: '#ff9800',
},
page: { bg: '#F5F6FA' },
```

组件库建议：**shadcn/ui**（Button、Input、Select、Table、Dialog、Toast），按本规范覆写 variant。

---

## 11. 禁止事项

- ❌ 彩虹色按钮无语义堆砌
- ❌ 在 Web 端提供「静默覆盖库存」的导入交易能力（与 PD 一致）
- ❌ 登录页暴露大块数据库技术配置
- ❌ 下拉列表高度不足（必须满足 ≥6 行可视空间）
- ❌ 冲销记录提供编辑/删除入口
