## 1. 产品一句话

Lightweight desktop WMS for internal inventory tracking, stocktakes, and inbound/outbound records.

中文：面向公司内部的轻量级桌面仓库管理系统，用于库存盘点、物料维护与出入库追溯。

---

## 2. 背景与目标

### 2.1 背景

弘盛非洲机电需要一套**单机可运行、易维护**的仓库工具：不依赖服务器部署，双击 exe 即可使用；以「当前库存量」为权威数据，交易记录用于流向追溯。

### 2.2 产品目标

1. 完成库存主数据维护与状态预警（正常 / 预警 / 缺货）。
2. 通过正式出入库操作变动库存，并保留可审计的交易记录。
3. 支持 CSV 备份与库存导入，便于盘点后批量更新。
4. 可选将本地 SQLite 覆盖同步到远程 PostgreSQL，便于云端备份/只读查询。
5. 以 React 桌面壳交付，业务逻辑集中在本地 FastAPI + `db_manager.py`。

### 2.3 非目标（Out of Scope）

| 项 | 说明 |
|----|------|
| 多仓库 / 多租户 SaaS | 不做 |
| 内网浏览器独立部署 | 已取消；API 仅 `127.0.0.1` |
| 移动端 App | 不做 |
| ERP / 财务对接 | 不做 |
| 条码枪 / RFID | 不做 |
| 导入交易并自动改库存 | 明确禁止 |
| 多角色权限 | v1 仅单一管理员账号 |
| 从云端回写本地库存 | 同步为本地 → 远程覆盖，单向 |

## 5. 业务规则（铁律）

1. **`current_stock` 是权威库存**；交易记录用于审计与查询。
2. **库存变动途径**仅限：入库、出库、冲销、删除/编辑交易回滚或差额调整、库存 CSV 导入 upsert。
3. **导入交易记录不得自动改库存**（当前产品亦不提供交易导入）。
4. **类目唯一、条目唯一**；尽量避免同物多地点分散存放。
5. **入库必填来源柜号**；出入库不修改 `Inventory.cabinet`。
6. **冲销类交易不可再编辑/删除**（通过冲销纠错）。
7. API **仅绑定本机**；JWT 鉴权保护业务接口。

### 5.1 库存变动一览

| 途径 | 是否改变库存 | 说明 |
|------|-------------|------|
| 入库 IN | 是 | 正式操作 |
| 出库 OUT | 是 | 需库存充足 |
| 冲销 REVERSAL | 是 | 生成新记录，保留原记录 |
| 删除交易 | 是 | 回滚；禁删冲销 |
| 编辑交易 | 是 | 差额调整；禁改冲销 |
| CSV 导入库存 | 是 | 组合键 upsert |
| CSV 导入交易 | 否 / 不支持 | — |
| 云端同步 | 否（本地） | 只推送远程副本 |

## 8. 系统架构

```
desktop/launcher.py（exe 入口）
    ├─ pywebview 窗口 → http://127.0.0.1:8000/
    └─ uvicorn → FastAPI (backend/)
            ├─ /api/*  REST + JWT
            └─ /       静态 React（frontend/out）
                    ↓
            db_manager.py + data_utility.py
                    ↓
            SQLite（exe 同目录 db/honsen_storage.db）
                    ─可选覆盖同步→
            远程 PostgreSQL
```

| 层 | 技术 |
|----|------|
| UI | React、Next.js、TypeScript、Tailwind |
| 桌面壳 | pywebview（WebView2） |
| API | FastAPI、Pydantic、uvicorn |
| 业务 | `db_manager.py` |
| 本地库 | SQLite |
| 远程备份 | PostgreSQL（psycopg2） |
| 打包 | PyInstaller |
