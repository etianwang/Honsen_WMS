# Honsen_WMS (仓库管理系统)

###  项目简介
本系统是一个轻量级仓库管理系统，专为满足公司内部库存盘点与记录需求而开发。<br>
设计初衷在于**简单、高效、易维护**，致力于通过极简的架构解决核心库存追踪问题。

---

###  核心设计理念
在使用本系统前，请务必理解以下设计原则：

* **库存记录为核：** 系统逻辑围绕“当前库存量”展开。交易记录作为辅助，主要用于追踪物品流向。
* **简洁即是效率：** 本项目旨在满足业务痛点，不过度工程化，专注于能落地的实用功能。
* **严谨的数据录入：** 系统依赖于规范的数据录入，请遵循下述规则以确保数据准确。

---

### [WARN] 使用规范 (必读)

为了保证系统数据的完整性和可追溯性，请全体用户严格执行以下录入准则：

1. **类目唯一性：** 同一类别物品请归纳至唯一类目下，严禁多头定义。<br>
2. **条目唯一性：** 同一物品请保持名称/条码唯一。<br>
3. **避免分散储存：** 尽可能避免将同一物品分散在多个仓库区域储存，以减少盘点难度。<br>
4. **关于交易记录：**<br>
   - 本系统暂不支持“导入覆盖交易记录”。<br>
   - 导入的交易记录仅作为历史审计依据，**不会自动触发库存数量增减**。<br>
   - **库存变动请务必在系统中进行正式的出入库操作。**<br>
5. **备注建议：** 若需详细描述出入库用途，请直接记载在“接收人”或“备注”栏中，以保持记录的连贯性。

---

###  技术栈与开发初衷
* **交付形态：** **React（Next.js）** 界面 + 本地 FastAPI + **pywebview**，PyInstaller 打包 exe（非浏览器 Web 站）。<br>
* **开发背景：** AI 辅助开发，致力于解决公司内部管理痛点。<br>
* **定位：** 内部自用工具，重在“能用”、“好用”。

### ▶ 开发运行

```powershell
# 前后端分离开发（推荐，支持热更新）
# 终端 1 — API
cd E:\Project\Py\wms
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.main:app --reload --port 8000

# 终端 2 — React
cd frontend
npm install
npm run dev
# 浏览器打开 http://localhost:3000
```

### ▶ 桌面预览与打包

```powershell
cd frontend && npm run build:desktop
python desktop/launcher.py

# 一键打包 exe
.\scripts\build-desktop.ps1
# 输出：dist\Honsen WMS.exe
```

数据库：`db/honsen_storage.db`（exe 旁 `db/` 目录）。初始化见 React 登录页「初始化数据库」。
